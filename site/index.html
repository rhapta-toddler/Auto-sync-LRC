What it does

Timing lyrics by hand means pausing and scrubbing through a song line by line. Auto-sync-LRC listens to the song for you and writes the timestamps.

Any language

English, Spanish, French, German, Portuguese, Russian, Japanese, Korean, Mandarin, Cantonese and every other language the Whisper speech model understands.

Private by design

Speech recognition runs on your own computer. Only text is sent to the AI service, never the audio. Your API key stays on your machine.

No guessed files

Every result is checked: each line is covered, times always move forward and stay inside the song. If it cannot be made reliable, no file is written.

Works with your player

Standard .lrc output, saved right next to the song, for foobar2000, MusicBee, Poweramp, AIMP, car stereos and other lyrics-aware players.

Keeps your structure

Tags like [verse] and [chorus] and blank lines stay in place, untimed, so the file still reads the way you wrote it.

Point and click

A simple window on Windows. For power users there is also a command-line tool, a pip package and a Docker image.

How it works

Two steps, each doing what it is best at.

1

Listen

The Whisper speech-recognition model runs locally and finds when each word is sung.

2

Match

An AI model (Anthropic Claude or an OpenAI model, with your own key) lines your clean lyrics up with those timings, line by line.

3

Check and save

The timings are validated, then song.lrc is saved next to song.mp3.

Install

Windows takes about a minute. No administrator password needed.

  1. Download Auto-sync-LRC-Setup.exe and double-click it.
  2. If Windows says "Windows protected your PC", click More info, then Run anyway. The app is new and not yet code-signed; the installer is built in public by GitHub Actions from the open source code.
  3. Click Next, Install, Finish. In the window: choose your song, paste the lyrics, pick the language, paste your API key, and click Create synced lyrics.
What you need: an API key from Anthropic (Claude) or OpenAI, billed by them for a few lines of text per song, and about 3 GB of free space the first time, for the speech model. Choose Balanced or Fast for a smaller download and quicker results.

Mac, Linux and developers

No one-click installer for Mac or Linux yet. Install with pip (this also gives you the auto-sync-lrc-gui window):

pip install git+https://github.com/rhapta-toddler/Auto-sync-LRC.git
export ANTHROPIC_API_KEY=sk-ant-...
auto-sync-lrc song.mp3 lyrics.txt --language ja

Docker, OpenAI-compatible providers and every option are in the README.

Questions

What is an LRC file?

A plain-text lyrics file where every line starts with a timestamp such as [01:23.45]. Players that support it highlight each line as it is sung.

Is it really free?

Yes, free and open source under the MIT license. It uses your own API key from Anthropic or OpenAI to match the lyrics. That service bills you directly and only receives a few lines of text per song.

Is my music uploaded anywhere?

No. Speech recognition runs on your computer. Only text (your lyrics and the words heard, with their timings) goes to the AI service.

Which languages work best?

Widely spoken languages work well at every setting. For Cantonese and other less common languages or dialects, use Best quality, because smaller speech models can mistake Cantonese for Mandarin, and check the result more carefully.

Why does Windows warn me about the installer?

The app is not yet code-signed, so SmartScreen does not recognise it. Click More info, then Run anyway. You can read every line of the source and the build on GitHub.

Does it work on Mac or Linux?

Yes, with pip or Docker (see above). A one-click installer is Windows-only for now.
